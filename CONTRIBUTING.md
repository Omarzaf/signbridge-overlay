# Contributing

Begin with `AGENTS.md` and `PROJECT_CONTEXT.md`. Each change should have one
clear owner, one bounded branch or worktree, and evidence from the native
verification commands.

Do not add sign-language mappings, signing media, participant data, or model
output as authoritative content without the review and rights records defined
in `docs/linguistic-safety.md` and `docs/licensing-and-consent.md`.

Dependency additions, external calls, public pushes, and deployments require
explicit approval. Security, privacy, accessibility, linguistic accuracy, and
media rights are release conditions rather than backlog items.
