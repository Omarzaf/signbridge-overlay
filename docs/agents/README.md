# Agent Routing

The Coordinator owns scope, integration, moderation, and human checkpoints.
Specialists work in dependency-ordered waves with no more than three active in
parallel.

## Foundation

- Architect: contracts, boundaries, threat model, and architecture decisions.
- Research: signed-language scope, rights, consent, and claims.
- Coordinator: repository, integration, verification, and moderation.

## Core

- Frontend runtime: overlay, synchronization, accessibility, and browser tests.
- Data/contracts: schemas, validators, manifests, and authoring constraints.
- Research: reviewed golden pack and human-review protocol.

## Delivery and validation

- Extension specialist: Manifest V3 and YouTube lifecycle.
- Offline specialist: PWA, local files, caching, quota, and eviction.
- DevOps: cloud preview, secrets boundary, logs, and reproducibility.
- Reviewer UI: correction workflow and publication gate.
- QA/accessibility: device, visual, interaction, and evidence audits.
- Writer: product documentation, demo, and contest submission drafts.

A fluent Deaf reviewer is a human authority, not a specialist agent.
