# ADR 0002: Begin with reviewed human signing media

## Decision

The first release uses rights-cleared upper-body human signing clips approved by
a qualified Deaf reviewer.

## Rationale

A convincing signing avatar requires motion, facial grammar, linguistic data,
and validation assets that are not present. An avatar-first build would create
technical spectacle before linguistic reliability.

## Consequences

- Media rights, consent, storage, and withdrawal are first-class requirements.
- SignPack publication must bind the exact approved hashes.
- Avatar research remains a future, separately validated track.
